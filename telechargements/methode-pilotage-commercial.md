# La méthode du cours · Pilotage commercial augmenté par l'IA

Fichier de contexte pour le projet Claude du groupe. Il résume la méthode du cours. Il ne contient aucune donnée d'entreprise.

## Le cycle de vente BtoB

Huit étapes : veille, prospection, qualification, rendez-vous, proposition, négociation, suivi, fidélisation.
Une tâche répétitive, rédactionnelle ou de synthèse peut s'augmenter. La relation et la décision restent humaines.

## La consigne en cinq éléments

Rôle, contexte, tâche, format, contraintes. On itère dans le même fil : on précise, on ne recommence pas.
Un exemple de réponse attendue améliore fortement le résultat.

## Les trois limites de l'IA

- Hallucination : une réponse fausse, écrite avec assurance. Tout fait se vérifie.
- Biais : l'IA reproduit les déséquilibres de ses données.
- Date de coupure : elle ignore ce qui suit son entraînement, sauf recherche web.

## Prospecter entre professionnels (RGPD)

- Un e-mail professionnel nominatif est une donnée personnelle.
- La prospection par e-mail est possible sans accord préalable si la personne est informée, si le message concerne son poste et si elle peut s'opposer dans chaque message.
- Pas d'extraction automatique de profils LinkedIn.
- Aucune donnée confidentielle d'une entreprise dans un outil d'IA public.

## Qualifier un prospect

Besoin, budget, décideur, calendrier : un point par critère, sur 4. Le centre d'achat compte quatre rôles : utilisateur, prescripteur, acheteur, décideur.

## L'application Apps Script

Une page web hébergée gratuitement par Google. Le code tourne chez Google. Les données vivent dans un Google Sheets. Gmail prépare les brouillons et les relances. Google Agenda reçoit les rendez-vous, dans un agenda dédié.
Claude écrit le code. Le groupe décide, teste et vérifie.

## Les règles du groupe

- Données toujours fictives ou anonymisées : jamais le vrai fichier clients.
- Les contacts sont désignés par leur fonction, avec une adresse alias de la boîte du projet.
- Aucune clé ni aucun mot de passe dans le code : réglages et clé d'API dans les propriétés du script.
- Une conversation, une fonctionnalité.
- Chaque chiffre cité par l'IA se vérifie à la source.
